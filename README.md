# Клинок Ёми

Мобильная браузерная idle-RPG в японском сеттинге, в духе Slayer Legends. Герой сам бежит по дорогам старой Японии и рубит ёкаев, а игрок тренирует его за золото, собирает и надевает снаряжение и прокачивает навыки. Доната нет: сила берётся только из игры.

- Список задач: [ROADMAP.md](ROADMAP.md)
- Стек: Phaser 3, TypeScript, Vite. Сохранения в localStorage, сервер не нужен.
