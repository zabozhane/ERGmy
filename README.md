# Клинок Ёми

Мобильная браузерная idle-RPG в японском сеттинге, в духе Slayer Legends. Герой сам бежит по дорогам старой Японии и рубит ёкаев, а игрок тренирует его за золото, собирает и надевает снаряжение и прокачивает навыки. Доната нет: сила берётся только из игры.

- Список задач: [ROADMAP.md](ROADMAP.md)
- Стек: Phaser 3, TypeScript, Vite. Сохранения в localStorage, сервер не нужен.

## Запуск
```
npm install
npm run dev
```
Vite покажет адрес в локальной сети, его можно открыть с телефона в том же Wi-Fi.

## Устройство
- `src/data.ts` — классы, оружие, слоты, главы, враги, задания
- `src/state.ts` — сохранение, формулы статов, предметы, экономика
- `src/game/battle.ts` — симуляция боя: бег, враги, удары, навыки, лут
- `src/game/BattleScene.ts` — сцена Phaser, рисует бой в текстуру
- `src/art/` — временная графика кодом (герой, ёкаи, фоны), заменится спрайтами
- `src/ui/ui.ts` — интерфейс: шапка, задания, навыки, вкладки, выбор героя
- `docs/ACTS.md` — акты, локации и боссы; `docs/refs/` — референсы
